# Metacritic ID crosswalk — 2026-10-06

The score lookup no longer joins or validates by display title. Site game IDs are retained; each is connected to an explicit Steam app ID and reviewed Metacritic resource ID. Immutable numeric Metacritic IDs are attached when unambiguously supplied by Wikidata P12078 (including qualifiers on P12054). Numeric IDs corroborate URL aliases; no fuzzy title, punctuation, edition suffix, or roman-numeral matching is used. A URL identifier is read from an actual source link, never generated from the game title.

## Reproducible files

- `metacritic-score-input.json`: numerical facts and source row IDs from leinstay/steamdb release 2026-10-05. Only relevant numerical facts are redistributed, with GPL-3.0 attribution and license retained. The source row update time does not establish when a score was measured. Critic scores are not imported into this subset.
- `metacritic-identity-evidence.json`: pre-migration approved ID associations, public Store appdetails links, Wikidata ID assertions, explicit manual alias approvals, edition audit, and five supplemental GOG source-record links. All 546 initially missing Steam apps were queried successfully; 491 associated Wikidata entities were also inspected for explicitly sourced user-score statements, yielding no additional qualifying facts.
- `game-identities.json`: one relationship for each of the 1,323 current catalog IDs, including status, edition scope, evidence, optional numeric ID, score record ID, and score platform. Display names do not participate in the runtime lookup.
- `metacritic-users.json`: records keyed by a stable source row ID (`mc-user:steamdb:<sourceRecordId>`) or an explicit historical Wikidata record ID. Each records its Metacritic resource, metric, platform, date, and provenance.
- `METACRITIC-REPORT.json`: every remaining missing record and every recovered record; totals reconcile against the initial 777 scores and 546 missing games.

Run `node scripts/refresh-metacritic-scores.mjs` from the repository root to rebuild the score subset, identity crosswalk and report deterministically from the retained input. This does not rerun or replace the PC catalog, editorial descriptions, tags, media, or account data. The older PC finalizer also calls this ID-based score builder; its title-based score join has been removed.

The download `score-data-source.tar.gz` contains the complete score builder, resolver, catalog ID input, source fact subset, identity evidence, report template and license. Extract and run the same command from its root; no source credentials or private user data are included.

## Identity checks and limitations

Public Store appdetails was queried by exact app ID; the response's own `steam_appid` and game type were checked. Its Metacritic *critic* link is identity evidence only, never the source of a numerical user score or of the user score's platform. Store links and Wikidata connect IDs without equating titles. The immutable numeric Metacritic identifier P12078 is preferred for alias corroboration; some resources have no published numeric ID, and their approved external resource identifier remains stored directly.

Steam app IDs can persist through successor and edition changes. Known CS2/CS:GO, Witcher Remastered/original, Call of Duty hub/individual game, season/episode, expansion/base game and Rocksmith Learn & Play/older Remastered associations are excluded. Incorrect FF X/X-2 and LEGO Complete Saga source links were replaced with the proper identity, but their wrong-game numerical facts were not moved to the corrected resource. HITMAN World of Assassination and Hunt 1896 have their own resources; historical base-version metrics are not presented as their updated-edition scores.

Only an explicitly reviewed source record may supplement a missing app-specific numerical fact. Five GOG product IDs were checked through the public `api.gog.com/products/<id>` endpoint. For example, Bannerlord's Steam and GOG source rows can be linked through the established Metacritic work ID even though the Steam row itself has no user score. A different Steam row with a generic matching URL is insufficient (e.g. a different Marathon product, or the Guild Wars base game versus a trilogy).

The secondary scores' platform remains unknown. Neither Windows availability, the Store critic link's `/pc/` path, nor a user's PS5 screenshot establishes a PC user-score value. The two previously verified historical CC0 PC facts keep their explicit platform and historical date. The secondary source is not a live Metacritic feed. Additional primary numerical observations are handled separately below; unavailable imported facts do not establish absence of a Metacritic score.

Current runtime checks require the catalog game ID, Steam app ID, approved Metacritic resource ID, numeric ID when present, score record ID, metric and platform to agree. A reviewed relationship survives display-name changes. It is not a promise to detect every future edition change automatically; external relationship changes require a fresh identity audit and review.

## Primary numerical coverage correction — 2026-10-06

A successful external-ID join cannot supply a value absent from a dataset. The 883-score secondary/historical pass still left 440 catalog games without an imported score; 421 of those lacked a numerical value in that source, and 19 had unusable or ambiguous associations. Mortal Shell II already had the correct Steam app 2584270 / Metacritic numeric ID 1300689309 relationship, but had no row in the selected release.

`metacritic-reviewed-facts.json` supplies 18 reviewed primary PC observations as a separate input. Mortal Shell II's 7.8 average and 507 ratings come from the user-provided PC capture; the original screenshot is not republished. Other observations come from publicly retrieved cached Metacritic PC user-review pages and retain the crawler's relative age label. `snapshotDate` is the observation/import date, `retrievedAt` the retrieval time, and `scoreDate` remains null when the actual measurement time is unknown. Retrieval today does not make an old cached average a live score. Exact rating counts may sum the three rating buckets from a single observation; abbreviated totals and written-review counts are not invented as exact total ratings.

Reviewed facts are joined by catalog game ID, Steam app ID, approved resource ID and numeric ID when known. Inputs fail closed for unknown products, duplicate fact IDs, conflicting work IDs, wrong metrics, non-PC platforms, contradictory source URLs, absent capture/cache evidence and invalid averages. The input is retained through every secondary-source rebuild; source nulls cannot silently erase it. An explicit reviewed PC observation is preferred to a secondary value whose platform is unspecified. This is a reproducible reviewed import path, not an unattended scraper or live API integration.

Two explicit resource aliases were reviewed: Workers & Resources connects its legacy Store URL and current Wikidata resource through the exact same Steam app 784150; STALKER 2's current `chornobyl` resource is reviewed against existing app 1643320 / Wikidata Q10865101 / numeric ID 1300083333, with the primary publisher and release details corroborating the work. These are retained crosswalk records, not generic title/transliteration rules. Doki Doki Plus's punctuation discrepancy and other unreviewed aliases remain unapproved.

The resulting catalog has 901 scores and 422 remaining gaps: 311 unverified identities, 104 approved identities without an imported numerical fact, and 7 conflicts. The coverage report also separates missing source values from unusable associations and explicitly leaves actual Metacritic score availability undetermined. All 883 preceding scores are retained. The three source groups sum to the displayed total: 881 secondary facts, two historical Wikidata facts and 18 reviewed primary PC facts.

The primary numerical observations retain source rights and are not labeled GPL or CC0. No publisher descriptions, user-review prose, artwork, or screenshot files are included in this score input. They are independently attributed on the licenses page. Public primary pages can be blocked or only available as stale cached observations; no blocked request, undocumented internal API or authentication/anti-bot restriction is bypassed. The investigated ITAD percentage is a positive-rating share, not a 0–10 Metacritic average, and is not imported. No anonymous, documented repeatable numerical-average source with complete catalog coverage was established in this pass.

Explicit PC fact links open the PC platform view rather than a default console view. Runtime lookup rejects a contradictory platform query, including duplicate PC/console parameters. Unspecified-platform secondary records remain unspecified.
