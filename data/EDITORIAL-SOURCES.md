# Game-specific Turkish discovery copy — 2026-10-06

`public/editorial.json` now covers every one of the 1,323 current PC catalog identities. Each catalog card has a distinct original Turkish discovery sentence tied to an actual game premise, mechanic or setting. The 37 previously written hooks that match current catalog titles are preserved, including Kenshi, Valheim, Cyberpunk 2077 and Stardew Valley. Missing extended text uses the existing hook rather than a generic catalog paragraph; newly researched entries have an original short explanatory body.

Research used 1,323 title/app-ID-matched factual profiles: 1,215 descriptions from the already downloaded 4 October 2026 leinstay/steamdb snapshot and 108 successfully matched public publisher Store responses. Sparse slogans or update notices received 90 fuller public publisher descriptions. Super Hexagon's obstacle mechanic was also checked against Apple's official App Store editorial, https://apps.apple.com/us/mac/story/id1467792429. The factual inputs are not republished as a bulk copy of publisher prose. `editorial-provenance.json` retains each canonical identity, research URL/date and whether the site's existing hook was preserved; `EDITORIAL-REPORT.json` records coverage and duplicate checks.

Content is matched by app ID plus normalized canonical title, with a title index for original aliases. A store metadata refresh continues to use the editorial layer, so raw genre lists cannot overwrite the copy. The JSON request has a deployment-specific cache key. A future identity without approved copy receives an honest missing-description notice rather than an automatically invented genre hook.

Game screens use neutral product labels for world/playstyle tags, gallery loading, recommendation pages and positive store-review percentages. Technical source labels, source-weight tooltips and the external similar-items link are removed from game screens. The Steam-backed recommendation ordering, dated Metacritic user-score values and media requests retain their existing behavior. Exact provider attribution, GPL subset license/source downloads and the player license remain on `/lisanslar.html`; privacy information explains external media requests.

Validation checks complete catalog coverage, canonical identity, distinct hooks, absence of the former genre-template fallback, rendered neutral labels, in-site recommendation navigation, comparison, notes/library actions, media selection and escaping. The existing API/source/recommendation tests remain applicable. No managed browser QA capability is available; real browser visual inspection is not claimed.
